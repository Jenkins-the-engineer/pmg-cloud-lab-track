# PMG LAB 00 - ENGINEERING WORKSTATION AND GITHUB SETUP

## OBJECTIVE
Set up the core engineering workstation and version control environment for a pmg cloud lab track. This included installing the primary networking and development tools. Creating a Github account and repository. configuring Git locally. cloning the repository. and successfully making the first commit and push.

## TOOLS INSTALLED
- Cisco packet tracer
- wireshark
- npcap
- putty
- visual studio code
- Git
- Github
- diagrams.net

## TASK COMPLETED
- Installed the core networking and development tools for the pmg cloud track
- Created Github account Jenkins-the-engineer.
- installed and configured Git on local windows laptop
- Set the global Git username and email
- Cloned the Github repository to the laptop
- created initial lab folder structure
- Staged changes with git
- Created first Git commit
- Authenticated the laptop with Github
- Successfully pushed local changes to the remote Github repository

## verification
The setup was verfied by running Git commands successfully. Confirming the respository status showed clean workking tree, and checking Github to confirm that the committed lab files appeared in the remote repository.

## WHAT I LEARNED
I learned the basic relationship between Git and Github, including the difference between local files and remote repository. I practiced navigating directories from Git Bash, Creating folders and files, Staging Changes, committing changes, and pushing those changes to Github.

I also learned several basic cammand-line commands. including pwd, ls, cd. mkdir, and touch. I am still building confidence with these commancds, but i now understand what each one does and how they fit into a basic workflow
